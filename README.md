# 즐부 — 경매·등기 허브

부동산 경매·공매·셀프등기 실무가 즐부(박성찬)의 **강의 · 유튜브 · 저서 · 도구 · 챌린지 · 상담**을 한 화면에 모은 모바일 웹앱(PWA)입니다.

- 공개 주소: <https://zlbu.github.io/zlbu-hub/>
- 폰에서 열고 **홈 화면에 추가**하면 주소창 없이 앱처럼 열립니다. 한 번 열면 오프라인에서도 표지가 뜹니다.

## 화면

| 탭 | 내용 |
| --- | --- |
| 홈 | 브랜드 소개(경·공매 400건+ · 셀프등기 276건 · 저서 3권)와 챌린지·상담·카카오톡 바로가기 |
| 강의·유튜브 | 클래스유 기초강의, 클래스101 『경매근육』, 유튜브 `@zlbutv` 재생목록 7종과 추천 영상 |
| 전자책·도구 | 『경매근육』 『1억 근육』 『아무것도 아닌 암(앎)』 구매 링크, 크몽 1:1 컨설팅, 숨고 프로필 |
| 챌린지·상담 | 『경매근육』 2년 반 물건검색 챌린지 기록과 참여·상담 신청 |

## 구조

```
index.html      화면 전체 (4개 섹션)
styles.css      다크 네이비 + 골드 테마, 모바일 우선(900px 이상은 2단)
app.js          탭 전환 · 해시 주소(#store) · 설치 배너 · 서비스 워커 등록
manifest.json   앱 이름·아이콘·바로가기
sw.js           오프라인 캐시 (고친 뒤에는 VERSION 을 올려 주세요)
assets/         아이콘·배경·책 표지·공유 이미지
```

## 고칠 때

- 모든 링크는 `index.html` 안에서 바로 찾을 수 있습니다(강의 카드 `.course`, 재생목록 `.playlists`, 영상 `.videos`, 책 `.book`, 도구 `.tool`).
- 정적 파일만 있어 GitHub Pages·Netlify 어디든 그대로 올릴 수 있습니다. 하위 경로 배포를 위해 `manifest.json`의 `start_url`·`scope`는 `./` 기준입니다.
- 파일을 고친 뒤 `sw.js`의 `VERSION`을 올리지 않으면 이미 설치한 폰에서 예전 화면이 보일 수 있습니다.

## 안내

이 앱의 내용은 교육·컨설팅 안내이며 법률 자문이 아닙니다. 등기 대행과 소송 대리는 법무사·변호사 영역입니다.
